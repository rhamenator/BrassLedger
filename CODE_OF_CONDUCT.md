# Code of Conduct

## Our standard

Be respectful, constructive, and specific. Welcome people with different backgrounds and experience levels. Critique ideas and code rather than people. Harassment, threats, discriminatory language, deliberate disruption, and publication of another person's private information are not acceptable.

## Scope and enforcement

This standard applies in repository issues, pull requests, discussions, and other project spaces. Report conduct concerns privately to the repository owner through their GitHub profile. The maintainer may edit or remove content, restrict participation, or take other proportionate action to protect the community.

Reports will be handled as confidentially as practical. Retaliation against a good-faith reporter is prohibited.
